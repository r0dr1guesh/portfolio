# Proibição da exportação de carne bovina brasileira para a União Europeia

Introdução:
No dia 3 de setembro de 2026, exportação de carne bovina do Brasil para a União Europeia foi suspensa. O bloco europeu proibiu a importação de produtos de origem animal de países que utilizam determinados antimicrobianos e promotores de crescimento na pecuária que não seguem as normas do bloco. Com isso, esse projeto busca analisar os impactos da suspensão pro agronegócio brasileiro e quais possíveis mercados podem absorver o volume de carne bovina deixadas pelo mercado europeu a partir de dados públicos oficiais de exportação de carne do Brasil.

Fonte dos dados: Comex Stat (dados públicos)
